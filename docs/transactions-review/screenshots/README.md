# Transactions visual review

These are actual Chromium captures of a local production build using fictional, authenticated workspace responses. No production accounts, personal records, or credentials were used.

The before captures were taken from the existing PR #9 production build before rebuilding this branch (source tree equivalent to `origin/main` `93fb8ed`). The after captures were refreshed after the final implementation build. Both use the same records and fixed browser clock, 18 October 2026 in Asia/Kolkata; the application itself derives the current month dynamically.

The viewport images show the initial visible history and fixed mobile navigation. Full-page images show the complete ledger; Chromium captures the fixed navigation at its viewport position within that extended image. Browser checks separately verified that the final row can scroll above navigation and that detail sheets fit the viewport.

All 19 PNG files are generated by the scoped browser tests. The optional baseline capture command must be run against the original baseline build, not against a subsequent implementation build:

```sh
TRANSACTIONS_CAPTURE_BEFORE=1 npx playwright test --config=playwright.transactions.config.ts
npx playwright test --config=playwright.transactions.config.ts
```
